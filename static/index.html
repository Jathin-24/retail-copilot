Technical details (for evaluators)
Deterministic Python analytics over a local SQLite database are the single source of truth; Gemini only classifies intent and rephrases evidence, and never computes numbers. Answers are grounded via an explicit evidence layer (observed facts → calculated metrics → inference → recommendation → assumption). Policy and procedure questions are answered from a local embedding knowledge base (gemini-embedding-001, cosine top-k, index committed in data/retail.db), cited as POLICY EVIDENCE and kept separate from database analytics. Without a GEMINI_API_KEY the app runs in a fully deterministic fallback mode.
  • REST API: GET /api/health, GET /api/attention, POST /api/copilot/chat, GET /api/copilot/status, GET /api/analytics/*
  • Launch: pip install -r requirements.txt then python app.py (serves this page on port 8000)
  • Track: README first line TRACK_ID=PS6; app metadata PS03
