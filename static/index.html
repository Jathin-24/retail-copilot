    Architectural Foundations
    
      
    
        Strict separation of concerns ensures absolute numerical accuracy and zero hallucinations:
      
    
      
    
        
    
          
    1. Deterministic Python Core
    
          
    
            All aggregations, run-rates, margins, safety stock calculations, and anomaly detections are executed deterministically in Python using SQLite and Pandas.
          
    
        
    
        
    
          
    2. Grounded Gemini Reasoning
